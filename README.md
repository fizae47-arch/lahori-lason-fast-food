# 🍔 Lahori Lason POS

A full-stack Point of Sale (POS) system built for a fast-food restaurant to manage daily sales, menu items, categories, deals, orders, receipts, invoices, and earnings from a single application.

The system is designed for practical restaurant use, helping staff manage orders efficiently while providing management features for menus, deals, orders, and sales tracking.

## 🏗️ System Architecture

The application consists of two main parts:

### Frontend

The frontend provides the POS interface used for:

- Login
- Menu browsing
- Category management
- Deal management
- Cart management
- Order processing
- Receipt printing
- Order history
- Sales information

### Backend

The backend provides REST APIs for:

- Menu management
- Categories
- Deals
- Orders
- Invoice management
- Database operations
- Authentication-related functionality

### Database

MongoDB is used to store application data including:

- Menu items
- Categories
- Deals
- Orders
- Invoice information
